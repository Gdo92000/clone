# Utilitários e Serviços

Funções utilitárias e serviços de domínio do Flux Delivery.

## Utilitários

| Utilitário | Descrição |
|------------|-----------|
| `format` | Formatação de valores (moeda, data, telefone, etc.) |
| `toast` | Notificações toast (via Sonner) |
| `logger` | Logging estruturado |
| `constants` | Constantes da aplicação |
| `iconMap` | Mapeamento de ícones |
| `queryClient` | Cliente TanStack Query configurado |
| `paymentMethodsData` | Dados de métodos de pagamento |

## Serviços

| Serviço | Descrição |
|---------|-----------|
| `locationService` | Geolocalização e endereços |
| `geolocationService` | Geolocalização do navegador |
| `geocodeSearchService` | Geocodificação (via Nominatim/Photon) |
| `pricingUseCase` | Regras de precificação |
| `cityCoverageService` | Cobertura por cidade |
| `restaurantRepository` | Repositório de restaurantes |
| `authService` | Autenticação |
| `locationMachine` | State machine de localização |
