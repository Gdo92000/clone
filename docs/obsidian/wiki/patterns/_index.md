## Estrutura

Cada pattern tem seu próprio arquivo com:

- **Problema**: o que resolve
- **Solução**: como implementar
- **Exemplo**: código concreto
- **Trade-offs**: quando NÃO usar
- **Fontes**: links para os sources que embasam
