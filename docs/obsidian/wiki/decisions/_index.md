# Decisions

Decisões técnicas expandidas com contexto — ADRs enriquecidos que explicam não só o que foi decidido mas por que, quais alternativas foram consideradas, e o que se aprendeu depois.

## Formato

Cada decisão:

- **Contexto**: o problema ou oportunidade
- **Alternativas**: opções consideradas
- **Decisão**: o que foi escolhido
- **Consequências**: o que aconteceu depois (aprendizados)
- **Fontes**: links para sources relevantes

---

*Decisões são o "pra sempre" — registram a inteligência que o time acumulou.*
