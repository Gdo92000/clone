# Sources

Coleção imutável de documentos brutos. Artigos, docs de bibliotecas, papers, transcrições.

- **Imutável**: o LLM lê mas nunca modifica
- **Fonte da verdade**: o que está aqui sustenta o resto do wiki
- **Formatos**: `.md`, `.pdf`, `.html` (convertidos para markdown via web clipper)

## Diretrizes

1. Um source por arquivo
2. Nome descritivo: `react19-streaming.md` (não `article-123.md`)
3. Incluir metadados no frontmatter: url, data, autor
4. Após ingest, atualizar `index.md` e `log.md`
